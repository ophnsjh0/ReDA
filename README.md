# ReDA (Reply Draft Agent)

기술지원(TAC) 엔지니어의 Gmail을 대신 정리해 주는 에이전트입니다.

## 누구를 위한 에이전트인가

고객 장애·설정·케이스 문의 메일을 매일 많이 받는 기술지원 엔지니어를 위한 에이전트입니다. 엔지니어는 그동안 이런 일에 시간을 써 왔습니다.

- 답장할 메일을 고르는 일
- 같은 고객사의 지난 메일을 찾아 답장을 쓰는 일
- 메일 속 일정을 챙기는 일

ReDA가 이 일을 대신합니다.

- **분류:** 15분마다 새 메일을 `답장필요` / `확인필요` / `참고`로 나누고, 긴급도와 함께 Gmail 라벨을 붙입니다.
- **답장 초안:** 답장이 필요한 메일은 스레드와 같은 고객사의 지난 메일을 보고, 근거를 단 답장 초안을 Gmail 임시보관함에 넣습니다.
- **알림:** 출근 전에 처리 결과를 요약해 텔레그램으로 보내고, 급한 메일은 받는 즉시 알립니다.
- **일정:** 메일 속 일정은 버튼으로 확인받은 뒤 Google 캘린더에 등록합니다.

메일을 보내는 기능은 만들지 않습니다. 초안은 사람이 읽고 직접 보냅니다.

## 구성

- **분류:** 규칙 필터 + TypeSafe **Jev**. 판단은 Jev가 확률로 하고, 최종 결정은 코드의 판정표가 합니다.
- **초안:** **Hermes Agent**가 ReDA MCP 도구로 씁니다. 에이전트가 쓸 수 있는 동작은 스레드 읽기, 초안 저장, 보류, 라벨뿐입니다.
- **메신저:** Telegram 봇
- **코드:** Python 3.13, uv, SQLite (사용자마다 상태 DB 하나)

## 진행 상황

### 되는 것
- Gmail 연결, 15분마다 새 메일 가져오기 (개발용 Mac에서 실행)
- 규칙 필터와 Jev 분류, 라벨과 긴급도
  - 팀 메일(그룹 주소)은 인사말과 담당 이력으로 내 일인지 판단합니다
- 근거 블록이 달린 답장 초안 자동 작성
  - 근거가 없는 내용은 `[확인 필요]`로 남깁니다
  - 메일 속 지시를 이용한 공격(프롬프트 인젝션) 시험 10종을 모두 통과했습니다
- 고객 IP와 계정 정보는 LLM에 보내기 전에 가립니다
- 텔레그램으로 출근 전 요약과 급한 메일·일정 메일 알림
- 메일 속 일정 제안 → [캘린더에 등록] [시간 수정] [무시] 버튼 → Google 캘린더 등록
  - `stage-9-schedule` 브랜치에서 동작을 확인했고, 아직 합치지 않았습니다
- 자동 테스트 380여 개, 메일 발송 차단 검사, 공개 저장소 위생 검사

### 아직 안 되는 것
- 실제 메일 1주일 검증: 진행 중입니다. 분류 정확도와 초안 품질을 확인하고 기준을 고칩니다
- VPS 배포: 지금은 개발용 Mac에서만 돕니다
- 일정 기능과 알림 봇 통합
- 다른 사용자 연결 (Google "허용"만 누르면 연결되는 흐름), 팀원·팀 추가
- 첨부 파일 분석, 기술 문서 검색, 캘린더 기반 주간보고

## 실행 (개발용)

```bash
uv sync
cp .env.example .env          # 주소, 분류기 키 등 설정
uv run reda gmail auth        # Google 동의
uv run reda poll --dry-run    # 메일함을 바꾸지 않고 확인
uv run reda poll              # 분류하고 라벨 붙이기
uv run pytest                 # 테스트
```

자세한 계획과 결정 사항은 `기획안/`에 있습니다.
